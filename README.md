# Expense Tracker 

## About the Project
Expense Tracker is a simple Python-based application that helps users manage and track their daily expenses.

Users can add, view, search, and delete expense records. It also calculates the total amount spent and stores expense data permanently using a JSON file.

## Features

- Add new expenses
- View all expenses
- Search expenses using Expense ID
- Delete expense records
- Calculate total expenses
- Store data in a JSON file
- Load previously saved expense records

## Technologies Used

- Python
- JSON
- Dictionaries
- Loops
- Conditional Statements

## Expense Details

Each expense contains:

- Expense ID
- Expense Name
- Amount
- Category
- Date
